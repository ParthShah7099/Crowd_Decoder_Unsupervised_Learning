## Reporting a Vulnerability

This is an academic machine learning project with no credentials or private data.  
The only dataset is the public Kaggle *Mall Customer Segmentation Data* (CC0) — it holds no names or contact details.

If you discover a security concern (e.g., accidentally committed credentials or personal data), please:

1. **Do not** open a public GitHub issue
2. Contact the maintainer directly:  
   👉 [LinkedIn — Parth Shah](https://www.linkedin.com/in/parth-shah-28387532b/)
3. Include a description of the concern and steps to reproduce

The maintainer will respond within 48 hours.
