Thank you for your interest in contributing to this project!  
This is an academic unsupervised learning submission, but feedback, bug reports, and learning contributions are always welcome.

---

## 🐛 Found a Bug?

1. Open an [Issue](https://github.com/ParthShah7099/Crowd_Decoder_Unsupervised_Learning/issues)
2. Title format: `[BUG] — short description`
3. Include: which cell fails, the exact error message, and your Python + library versions (Task 7.5 prints them)

## 💡 Have a Suggestion?

1. Open an [Issue](https://github.com/ParthShah7099/Crowd_Decoder_Unsupervised_Learning/issues)
2. Title format: `[SUGGESTION] — short description`
3. Explain what improvement you'd like and why

## 🔧 Want to Submit Code?

1. Fork this repository
2. Create a branch: `git checkout -b feature/your-improvement`
3. Make your changes
4. Commit: `git commit -m "Add: brief description"`
5. Push: `git push origin feature/your-improvement`
6. Open a Pull Request

---

## ✅ Contribution Standards

- Keep the code style consistent — Hinglish comments, emoji task headers, `─── ───` separators
- Only use libraries already in `requirements.txt`
- Keep `random_state=42` so every result stays reproducible
- Every plot needs a title, labelled axes, a legend where it applies, and the red `#CC0000` accent
- Explain every chart in a markdown cell right below it
- Test with **Runtime → Restart session and run all** before submitting
- Do not modify `Mall_Customers.csv` — it is the original Kaggle data
